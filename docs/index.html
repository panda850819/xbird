How it works

01

Use your existing session

Cookie auth. No password prompt. Reads from Safari/Chrome/Firefox (configurable).

02

GraphQL first

Talks to X’s internal endpoints. Query IDs rotate — xbird auto-refreshes and caches them.

03

Fast, scriptable output

Human output by default. Flip to --json or --plain when you need stability.

!

Undocumented API.

xbird uses X/Twitter’s private web GraphQL endpoints and rotating query IDs. X can change things anytime — expect breakage without notice.
